# START HERE — V3

1. Replace the current project with this V3 package and commit to the existing GitHub repository.
2. Let Netlify deploy automatically.
3. Open `/kontakt/` and submit a test message.
4. In Netlify, configure the email notification for the `kontakt` form.
5. Later add `PUBLIC_GA_ID` and `PUBLIC_GOOGLE_SITE_VERIFICATION` as Netlify environment variables.

Do not create a new repository.
